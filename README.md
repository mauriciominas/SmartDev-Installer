## Versão em Português

Interface gráfica moderna (estilo Rufus) para automatizar a configuração e instalação de ferramentas de desenvolvimento no Windows através do Winget.

Este repositório contém os arquivos organizados em duas pastas independentes por idioma:
* 🇧🇷 **[pt_br/](pt_br/)**: Contém o executável, código Python e script Batch em **Português do Brasil**.
* 🌎 **[en/](en/)**: Contém o executável, código Python e script Batch em **Inglês**.

## English Version

Modern Rufus-style GUI wrapper to automate the installation and configuration of development tools on Windows using Winget.

This repository organizes the installer into two independent language directories:
* 🇧🇷 **[pt_br/](pt_br/)**: Contains the executable, Python wrapper, and Batch script in **Brazilian Portuguese**.
* 🌎 **[en/](en/)**: Contains the executable, Python wrapper, and Batch script in **English**.
