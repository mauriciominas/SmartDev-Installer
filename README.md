## Versão em Português

Interface gráfica moderna para automatizar a configuração e instalação de ferramentas de desenvolvimento no Windows através do Winget.

Este repositório contém os arquivos organizados em duas pastas independentes por idioma:
* 🇧🇷 **[pt_br/](pt_br/)**: Contém o executável, código Python e script Batch em **Português do Brasil**.
* 🌎 **[en/](en/)**: Contém o executável, código Python e script Batch em **Inglês**.

### ⚠️ AVISO DE ISENÇÃO DE RESPONSABILIDADE
1. **Uso por sua Conta e Risco:** Este software é fornecido "no estado em que se encontra", sem garantias de qualquer tipo.
2. **Modificação de Sistema:** Este programa executa modificações de sistema que requerem privilégios de administrador (UAC).

### 📋 Requisitos do Sistema
* **SO:** Windows 10 (1709 ou superior) ou Windows 11.
* **Dependências:** PowerShell 5.1+ e `winget` instalados.
* **Privilégios:** Administrador (UAC).

Leia mais detalhes de uso diretamente na documentação da pasta [pt_br/](pt_br/).

## English Version

Modern GUI wrapper to automate the installation and configuration of developer environment tools on Windows using Winget.

This repository organizes the installer into two independent language directories:
* 🇧🇷 **[pt_br/](pt_br/)**: Contains the executable, Python wrapper, and Batch script in **Brazilian Portuguese**.
* 🌎 **[en/](en/)**: Contains the executable, Python wrapper, and Batch script in **English**.

### 📋 System Requirements
* **OS:** Windows 10 (1709 or newer) or Windows 11.
* **Dependencies:** PowerShell 5.1+ and `winget` installed.
* **Privileges:** Administrator (UAC).

Read further details directly in the documentation of the [en/](en/) directory.
